Travel poster for a place that does not exist: VAELMOOR on the Nordmark Isles — dusk sun, stone arch, tide-lit lighthouse.
A flat vintage travel poster, 1024×1024 PNG (168 KB): dusk sky over the Nordmark Isles, a rising sun, a stone arch on the headland and a tide-lit lighthouse — an invented place, VAELMOOR, set into the picture. The entrypoint ships the rendered PNG: it copies `entry.png` to `/output/entry.png`, byte-identical on every run (the grader sandbox has no fonts or image libraries, so nothing is rendered at runtime).

## Run it

```sh
node main.ts          # copies entry.png to $MAKEFUN_OUTPUT_DIR or /output
```
